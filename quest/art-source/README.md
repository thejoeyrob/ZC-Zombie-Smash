# Art source folder

Everything the VR arcade's artwork is built from. `tools/assemble_art.py` turns this folder into the pictures in `vr-art/`.

| Folder / file | What it is |
| --- | --- |
| `debo-side-chatgpt.png` | The Debo painting (basketball court). Used for his machine side and header. |
| `poster-1..6.png` | The six framed posters (zombie crowd, Jordan, Disco, Dr Mantis, Glowing zombies, Sloth). Also used as side art and headers for Jordan, Glowing Humanity and Caffeinated Sloth. |
| `comics/` | Comic pages (Fat Amy, Glowing Humanity, Jordan) used as framed wall art. |
| `chatgpt-round2/` | The strongest pieces from the second ChatGPT round: side art and headers for Disco, Fat Amy, Dr Mantis and Joey Rob, plus the brick wall with its normal and roughness maps. |

Other artwork already in the project: `vr-art/` (room textures, signs, stickers, jukebox, decals), the root folder (game sprites, arenas, boss art, comic videos).
Not used on purpose: ChatGPT's 3D models (basic shapes), its flat neon signs and stickers (ours look better).
