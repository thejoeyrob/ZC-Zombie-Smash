# 7.50.0 — retro console and indicator lamps

- New Retro Handheld shell (`console-retro-handheld.webp`) replaces the superseded vector shell, which is deleted. The supplied art was re-fitted to the immutable 375 × 667 layout (screen window `win: [72,98,828,1165]`, socket centres on the real control centres); no other skin or shared asset was touched. Skin id is unchanged, so installs on the old retro skin pick up the new one and anyone who chose another skin keeps it.
- Controls are the supplied sprites (`retro-stick/fire/grenade/menu.png`, three frames each) drawn over the unchanged hit areas, sized in % of each control. Joystick: left / centre / right (±30 % of travel). Fire: normal, pressed, lit (tutorial hint). Grenade: lit while grenades remain, pressed on tap, dim at zero; the count badge is kept. Menu: normal, pressed, lit while the menu is open. The supplied sheets have no separate "disabled" frame, so disabled is the normal frame dimmed. The menu keycap was widened (face stretched, icon untouched) to fit the console's slot.
- Top-right power lamp, every skin: dormant (menu / game over), steady red (play), blinking red (exactly one heart), red/green alternation for 1.7 s on a camp breach (takes priority). Reduced motion: low health is a steady red with a halo, a breach is steady green for the same time.
- Lower red lamp, retro skin only: dark, one brief flash every 4 s when a stored special weapon is available, steady red while a non-pistol or arena weapon is equipped; dormant at game over. Reduced motion: steady half-lit instead of flashing.
- Lamps are driven by `ZSConsole.leds()` (pure, unit-tested) and three data attributes on `#cabinet`, updated through the existing HUD cache. Paused or hidden pages freeze blinking; timers are cleared on game over and restart.

Not done here: physical iPhone testing. Gamepad and keyboard movement leave the joystick sprite centred (the knob did not follow them before either).

## 7.52.0 — NES-inspired shell
The shell is now the charcoal-inset design from the NES-inspired pack (dot-matrix ZOMBIE SMASH plate, glass-lip screen bezel, JW EDS with four dots, no side stripes). The supplied art follows the original unwarped geometry, so it was re-fitted to the layout (screen window exact; each socket, and the lower lamp, lifted whole to the real control centres over a re-filled charcoal panel). The pack's separate sprites were not used: their frames differ in size from state to state (the joystick grows to the right, grenade/fire/menu vary) and the lamp sprites are cut in half; the existing sprite set is kept, resized to the new sockets, with the menu key widened to the new 2:1 slot. The map-name label under the deck is hidden on this skin because the new shell prints its own brand there.

## 7.53.0 — JW grey handheld (final retro default)
Shell, sprites and lamps are the JW grey handheld pack (yellow joystick, red FIRE, blue grenade, grey MENU, no controls baked into the shell). The shell was refitted to the immutable 375 × 667 layout (screen window exact, deck panel stretched to carry the real control centres, footer mark and speakers kept at natural proportions). The pack's own menu/fire/grenade "disabled" frames are not used. Lamp rules are unchanged from 7.50: dormant before play and at game over, steady red in play, blinking red at one heart, red/green alternation on a camp breach; the lower lamp is the special-weapon lamp. The old sprites and the previous shell are removed.
- **Top marquee (retro skin only, `led-display.js`):** a 5×7 dot-matrix display in the blank bar. It cycles ZOMBIE SMASH (yellow), WAVE n (green), the map name (amber), BOSS name (red, boss fights only) and the player name (green); messages roll up from the bottom, hold, and roll off the top, and wider text scrolls in from the right. Before a run it alternates ZOMBIE SMASH and PRESS START; at game over GAME OVER; while the menu is open PAUSED. Red alerts interrupt it: BREACH n/10, LOW HEALTH at one heart, and the name of an arena special weapon when one is won. It only draws while something moves, stops when the page is hidden, and shows a still message under reduced motion.
- **Studio intro:** flat white JW EDS mark on black eases in, the four colour blocks arrive one by one left to right, then it fades (about 3.7 s, tap to skip).
- MOVE and SPECIAL are live text labels, not part of the shell art.

## 7.54.0 — home and player screens
Home: logo, high score, flashing PRESS FIRE with "TO START GAME" under it (the FIRE button flashes too; FIRE, Space/Enter, a gamepad button or a tap on the text goes on), the boss silhouettes (lit when beaten) and the boss count. Player entry is its own black screen in retro-computer style (green outlined boxes): the saved name is shown locked with CHANGE to edit it (CHANGE is greyed out and the box open until a name has been entered once); NEW GAME goes to the story / start screen; CONTINUE · WAVE n appears only when a run was left half played; BACK returns home.
