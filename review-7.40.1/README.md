# Review pack for Zombie Smash 7.40.1 (commit 6f5d2b1)

Three zips, each under GitHub's 100 MB file limit. Unzip all three into the same empty folder to get the complete build.

- ZS-7.40.1-part1-code-art-audio.zip: code, art, music, sound effects, store text and screenshots
- ZS-7.40.1-part2-films-A.zip: Jordan, Glowing Humanity, Debo, Caffeinated Sloth films and the three opening films
- ZS-7.40.1-part3-films-B.zip: Disco Man, Fat Amy, Dr Mantis films

This folder exists ONLY on the branch `review-7.40.1`. It is not on `chatgpt-pro-build` or `main`, is never listed in sw.js, and scripts/build-www.mjs only copies files named in sw.js, so it can never end up in the app.
